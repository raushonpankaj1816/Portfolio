# Portfolio - Raushan Kumar

A static personal portfolio presenting my education, technical skills, selected projects, certifications, and contact information.

## About

I am a B.Tech Computer Science and Engineering student specializing in Cyber Security. This site is built as a static HTML and CSS portfolio.

## Features

- Responsive homepage with About, Education, Skills, Projects, Certifications, and Contact sections.
- Dedicated certificate gallery with category navigation.
- Dedicated project details page.
- Local certificate images and direct contact/social links.

## Technologies

- HTML5
- CSS3
- Font Awesome 6 via CDN for icons
- GitHub Pages for hosting and deployment
