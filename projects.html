An agriculture-focused front-end prototype built with HTML, CSS and JavaScript.

Overview

The repository contains a browser-based interface with profile and menu drawers, a location input, a forecast display, language controls and a chatbot panel.

Features in the Repository

  • An image slider with manual controls and automatic slide changes.
  • A location field that updates the displayed location and saves it in browser storage.
  • A seven-day forecast display populated with generated values.
  • Language controls for English, Hindi, Punjabi and Marathi.
  • A chatbot panel that accepts text and displays the submitted message.

Technologies Used

SIH 2025 Problem Statement Context

SIH25010: Smart Crop Advisory System for Small and Marginal Farmers. Organization: Government of Punjab. Category: Software. Theme: Agriculture, FoodTech & Rural Development. The challenge describes personalized agricultural advice, including crop selection, pest control, and soil- or weather-related guidance. These are problem-statement needs, not claims about implemented features.

The forecast values are generated in the front-end code, not retrieved from a weather service. The reviewed files do not show an AI model or external API integration; the chatbot panel only displays submitted text. Soil testing, pest detection, market price and government scheme items are navigation placeholders rather than verified working features.
