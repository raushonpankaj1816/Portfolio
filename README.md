# Portfolio — Raushan Kumar

Personal static portfolio website focused on Cyber Security, web development, education, projects and professional learning.

## Links
- **Live website:** https://raushonpankaj1816.github.io/Portfolio/
- **GitHub repository:** https://github.com/raushonpankaj1816/Portfolio

## Pages
- `index.html` — main portfolio
- `certifications.html` — 12 certificates grouped into Certifications, Technical Training, Internships and Participation
- `projects.html` — detailed information for the three projects
- `style.css` — shared responsive styling
- `.github/workflows/static.yml` — GitHub Pages deployment workflow

## Projects
### Personal Portfolio — 2024
Responsive portfolio built with HTML, CSS and Font Awesome. The site presents education, skills, projects and certifications.

Repository: https://github.com/raushonpankaj1816/Portfolio

### KisaanSahika — 2025
Agriculture-focused prototype for the Smart India Hackathon 2025 problem statement **SIH25010 — Smart Crop Advisory System for Small and Marginal Farmers**. The available project source supports a front-end prototype using HTML, CSS and JavaScript.

Repository: https://github.com/raushonpankaj1816/kisaansahika

### AI-Powered Email Threat Detection, GeoLocation and Forensic Intelligence Platform — 2026
Smart India Hackathon 2026 problem statement **PS 26106**, under Blockchain & Cybersecurity. The proposal covers email analysis, NLP/ML, header forensics, IP intelligence, geolocation, domain analysis, graph correlation and forensic reporting. The implementation source was not available for verification, so proposed components are not presented as confirmed working features.
